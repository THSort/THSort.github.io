AI Chat

Live since Feb 2026. Core engineer.

An agentic marketing suite that takes a business from idea to published campaign in one conversation. An orchestrator agent routes each turn to specialist subagents with 40+ tools on an extended NeuronAI framework, and streams back interactive UI such as surveys, option pickers and draft cards right inside the chat.

  • Designed its hybrid multimodal context layer, chosen over RAG-style retrieval: an image-description agent labels every asset and an asset-selection agent passes only the relevant images downstream. Shipped through an A/B-tested rollout, it cut workflow latency by 6–8s.
  • Grew it from a chat into a creation and publishing platform: fully editable layered designs, image-to-animation, turn-into-video, native transparent images, document ingestion and pasted-link reading.
  • Hardened it for scale: parallel agent graphs and stock search, retry loops for malformed structured outputs, credit metering and daily limits, Redis guards against duplicate generations, chat history and the feedback flow.
  • Made it measurable: per-agent token, cost and timing telemetry, DB-driven prompts with per-agent A/B variants, workflow tracing, an LLM eval harness and Playwright synthetic checks against production.

AI Websites

Beta. Lead engineer and architect.

An agentic website builder inside AI Chat that turns a conversation into a complete, editable website, streamed onto the canvas as the model writes it.

  • HTML is the source of truth and every edit is a reversible op on an append-only ledger, so agent edits and human drag-and-drop share one undo, history and restore. I chose it over JSON after a 160-turn A/B test in which JSON cost 1.7× more.
  • A planner splits each request into concurrent agent drives, and a custom partial-JSON stream decoder paints each section as it's written.
  • Four parallel code-review agents check every result, cutting review cost by 93% and turn latency by 56% while catching 31 known bugs where the previous reviewer caught 3.
  • Every page previews in a sandboxed iframe with its own CSP nonce, and a Journey Inspector lays out each turn's stages, tool calls and spans on a Gantt timeline.

03

AI Poster Customize

R&D, not launched. Architect.

Original AI result

Drag the divider to compare. Pick a template to see its brief. Prompts are illustrative.

An agentic pipeline that turns a one-line brief into finished posters by re-theming designs from PosterMyWall's library of 4M+ templates, without breaking the designer's layout.

  • Hybrid semantic search (CLIP embeddings plus keywords on Typesense) shortlists eligible designs and a vision model picks the best fits.
  • LLMs with structured outputs rewrite the copy and plan every image swap, sourcing stock and Getty assets ranked by multimodal embeddings on AWS Bedrock.
  • Deterministic code does the rest: zero-token text fitting, alpha-aware image placement and contrast-preserving palette re-theming in a headless Puppeteer and Fabric.js editor.
  • It began as a tool-calling agent that streamed edits live onto the canvas. Cost and consistency data drove the rebuild into a cost-bounded staged pipeline, hardened with async long-polling, queued imports and idempotent callbacks.

More from PosterMyWall

The pipelines and editor tools underneath the AI products.

Upload pipelines, rebuilt

Image uploads took a median 22.5s. I traced about 90% of the wait to fixed 2-second polling across ten sequential renderer calls, collapsed them into one queued job with sub-second polling, and shipped a cache-key fix through a zero-downtime, three-step rollout.

For video, I instrumented each step in CloudWatch first, then replaced a five-step renderer chain with one job that encodes the preview once at 850px and rebuilds high-res files from the original, which also made exports sharper. The p90 for video fell from 97s to 37s.

Subtitling for audio and video, which I architected: AI transcription with OpenAI, a React timeline for syncing and editing each line, and a custom Fabric.js grouped object that renders styled, animated, word-highlighted captions without slowing the canvas.
